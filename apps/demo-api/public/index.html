[03]Cómo funciona

Cuatro pasos y ningún tipo de cambio a mano.

Todo ocurre dentro del flujo x402 estándar. Si algo no cuadra, la transacción entera se revierte.

[01]

Precio local

El vendedor fija "70 NGN" en su ruta.

[02]

Oráculo Reflector

Lo pasa a USDC con la tasa on-chain, a favor del vendedor.

[03]

Paga con lo que tengas

USDC directo, o XLM y EURC con swap en Soroswap.

[04]

Recibo

USDC exacto al vendedor; el sobrante vuelve al cliente.

[04]Integración

Una línea por ruta.

Pones el precio en tu moneda y aceptas USDC, XLM y EURC con la misma cotización.

npm install local402-server

MCP, pero con límites.

Tu agente paga solo: verifica la tasa y respeta un tope por pago y un presupuesto.

…
// npm install local402-server
import { localRoute, local402Server } from "local402-server";

app.use(paymentMiddleware({
  "GET /africa": localRoute("70 NGN", { payTo }),
  "GET /uf": localRoute("0.01 UF", { payTo }),
}, local402Server()));
local402_discover  busca servicios (x402 Bazaar)
local402_quote     precio local y tasa
local402_pay       paga con USDC, XLM o EURC
local402_wallet    saldo y presupuesto
