¿Cuánto USDC es tu precio?

Cualquier monto en USD, UF o las 24 monedas de Reflector (MXN, BRL, EUR, INR, NGN, KES, JPY, CLP…), convertido con el oráculo, y lo que costaría ahora pagarlo con cada activo según el contrato FxPay.

Precio del vendedor
Cómo funciona

Del precio local al USDC del vendedor.

Todo ocurre dentro del flujo x402 estándar. Si algo no cuadra, la transacción entera se revierte.

01

Precio local

El vendedor fija "70 NGN" en su ruta x402.

02

Oráculo Reflector

Se convierte a USDC con la tasa on-chain, redondeando a favor del vendedor. La cotización viaja en el 402.

03

Paga con lo que tengas

USDC con exact. XLM o EURC con exact-fx: FxPay swapea en Soroswap en la misma transacción.

04

Recibo

El vendedor recibe el USDC exacto y el sobrante vuelve al cliente. Queda un recibo con tasa, fuente y transacción.

Para vendedores

Una línea por ruta.

Acepta USDC (exact) y XLM o EURC (exact-fx) con la misma cotización. También sirve para herramientas MCP con localToolPayment(server, "20 CLP", …).

server.ts
// npm install local402-server
import { localRoute, local402Server } from "local402-server";

app.use(paymentMiddleware({
  "GET /africa": localRoute("70 NGN", { payTo }),
  "GET /uf": localRoute("0.01 UF", { payTo }),
}, local402Server()));
Para agentes de IA

Tu agente paga, con los límites que tú fijas.

El agente verifica la tasa del vendedor con su propio oráculo, respeta MAX_PRICE y un presupuesto por sesión (BUDGET). En código: npm install local402-client.

Como servidor MCP (npx -y local402-mcp) le da cuatro herramientas: local402_discover, local402_quote, local402_pay y local402_wallet.

…
claude mcp add local402 \
  -e STELLAR_PRIVATE_KEY=S… \
  -e "MAX_PRICE=500 CLP" \

import { Agent, run, MCPServerStdio } from "@openai/agents";

const local402 = new MCPServerStdio({
  command: "npx",
  args: ["-y", "local402-mcp"],
  env: { STELLAR_PRIVATE_KEY: "S…", MAX_PRICE: "500 CLP" },
  clientSessionTimeoutSeconds: 30, // npx can take more than the default 5 s
});
await local402.connect();

const agent = new Agent({ name: "buyer", mcpServers: [local402] });
const result = await run(agent, "Pay https://local402.vercel.app/indicadores");
console.log(result.finalOutput);
await local402.close();
import { generateText, stepCountIs } from "ai";
import { anthropic } from "@ai-sdk/anthropic";
import { createMCPClient } from "@ai-sdk/mcp";
import { Experimental_StdioMCPTransport } from "@ai-sdk/mcp/mcp-stdio";

const mcp = await createMCPClient({
  transport: new Experimental_StdioMCPTransport({
    command: "npx",
    args: ["-y", "local402-mcp"],
    env: { STELLAR_PRIVATE_KEY: "S…", MAX_PRICE: "500 CLP" },
  }),
});
const { text } = await generateText({
  model: anthropic("claude-sonnet-5-5"),
  tools: await mcp.tools(),
  stopWhen: stepCountIs(5),
  prompt: "Pay https://local402.vercel.app/indicadores",
});
await mcp.close();
